First-time setup — install the Python sidecar
  1. Open a terminal in the project root and run: 
    cd server
pip install -e .[kokoro]
  2. Then restart JustVoice. The Tauri shell will spawn the sidecar automatically next launch.
  3. Or run the server manually in a separate terminal: npm run server

infoHeadless mode also available. Launch the Python sidecar standalone via justtts-server serve --port 17494. The same UI is served at http://localhost:17494/ui/ so you can run JustVoice on a remote box and hit it from any browser.

infoProfile vs Persona. A profile is a reusable voice configuration (cross-project) — voice + tuning + effects + personality. A persona is a named character in one project's cast bound to a profile. Two characters can share a profile; one profile can back many personas. Open Personas →

Apply a mastering preset

Upload a WAV, pick a preset, get a mastered MP3/M4A back. Requires ffmpeg on the server. ACX targets audiobook spec (−23 LUFS, −3 dBTP, head/tail silence). YouTube outputs AAC. Hits POST /v1/master.

About JustVoice v0.1.0

JustVoice is a cross-platform open-source voice production studio for audiobook producers, game developers, podcasters, dictation users, and accessibility users. Built on Tauri 2 + Vue 3 + Python FastAPI.
