JustVoice — UX feature inventory preview

Headless mode also supported. Same as upstream: the Python sidecar runs standalone via justvoice-server serve --port 17494. The Tauri shell is the desktop GUI; the headless server exposes the same HTTP API + serves the renderer at /ui/ so power users can run JustVoice on a remote box and hit it from any browser. Both modes share the same engine pool, voices, mastering, and SQLite store.
What you're looking at. A long scroll showing every planned tab + its features, side-by-side with which source it comes from. Aesthetic is intentionally neutral — visual direction (colors, type, density) is a separate decision later in Phase 4. This preview is for feature scope verification only.
