JustTTS — style explorations

Four directions for the admin GUI, each modelled on a real, currently shipping web product. Same Overview screen, same data, different visual vocabularies. Pick whichever feels right and I'll execute it cleanly across all six views.

01 Linear · Monochrome calm ref: linear.app · 2025 redesign
Type: Inter. Palette: white, near-black, one warm coral. Hairline 1px rules. Subtle rounded inputs. Status colour only on the dot — the kind of restraint Linear actually shipped when they cut their purple back to monochrome.
